# 一面一面・語文遊樂園

適合小學二年級、供兩位學生於電子白板遊玩的繁體中文語文遊戲。遊戲內使用書面語，沒有朗讀功能，無須 API 金鑰。

**線上遊戲：https://angusqaq.github.io/yi-mian-yi-mian-game/**

## 兩款遊戲

- **看圖判斷**：每回合六題，包含兩題合理、兩題不合理及兩題缺少主語。作答前不顯示答案；作答後顯示正確情境、醒目答案及簡短原因。缺少主語題採用動作特寫，並示範補上人物。
- **競賽造句**：兩位學生在左右畫面獨立操作。開始前倒數三秒，比賽六十秒。十八個動作每場分成兩組，各九個且完全不重複；兩個動作階段均提供該玩家完整九個選項。標點預先填入，完整且合理的句子得一分。賽後可點選所有句子看圖講解。

## 檔案與執行

本專案使用原生 HTML、CSS 及 JavaScript，圖片均包含於 `art/`。直接由 GitHub Pages 提供靜態網站，沒有伺服器資料庫或第三方生成 API。

本機預覽：

```sh
python3 -m http.server 8873 --bind 127.0.0.1
```

然後開啟 http://127.0.0.1:8873/ 。本機預覽需要 HTTP，因為遊戲會載入本地 JSON。

`index.html` 為入口；`app.js` 管理主頁及判斷題；`race.js` 管理競賽；`play.css` 定義版面；`data.json` 包含十八個動作、三百二十四種有序搭配的判斷及主語題；`art.json` 定義圖片圖集。

## 網站更新

GitHub Pages 使用 `main` 分支的根目錄。更新程式或圖片後推送至 `main`，GitHub 會重新部署。請保留此儲存庫及 Pages 設定，以維持固定網址。

## 圖片與練習紀錄

插圖由 ChatGPT 內建圖像工具生成，沿用兒童繪本風格；生成提示詞保留於 `docs/`。

分數與句子紀錄僅存在當前頁面，重新載入後清除。遊戲沒有登入、錄音或資料上傳功能。
